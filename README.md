# Installation

```
themeDarkmode-ux.jar
```

Copy the .jar file into your Niagara modules directory

Self-sign the module

Open Niagara and apply the theme

```
Tools > options > general > active theme > darkmode
```
If module does not show up, read log. Module potentially not signed or other issue

# Module signing

This module is not signed

You must self-sign the module before Niagara will allow it to run

I'm not that cool to pay for a CA to sign

# Required edits

Niagara does not allow themes to change default text editor input text

Instead, this can be changed within the Niagara settings

```
Tools > options > text editor > color coding > foreground > set to off-white of choice
```

# Notes

PxFile display is affected locally by the theme

The theme does not modify or permanently change the PxFile

Buttons, labels, text, etc may display differently

Example:

```
PxFile with white background, default (black) text, default (grey, highlight shadow) button
Displays as white background, default (white) text, default (black, no highlight shadow) button
```
